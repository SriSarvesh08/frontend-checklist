# Front-End Development Checklist 🚀

A hands-on learning repository covering front-end development fundamentals through practical tasks and mini-projects.

## 🎯 About This Repository

This repository documents my journey in learning front-end development, from HTML, CSS, and JavaScript fundamentals to modern frameworks such as React.

Each task focuses on applying concepts through practical implementation.

## ✅ Learning Progress

### 1. Web Tooling and HTML Basics
- Set up the development environment.
- Created a static profile webpage.
- Practised basic HTML structure and CSS styling.

### 2. CSS Fundamentals and Responsive Design
- Practised the CSS box model, Flexbox, and Grid.
- Built responsive cards and layouts.
- Used media queries for different screen sizes.

### 3. JavaScript and DOM Manipulation
- Selected and updated HTML elements using JavaScript.
- Handled user events.
- Built a task manager with task creation, completion, and deletion.

### 4. Asynchronous JavaScript
- Practised `async/await` and Promises.
- Used `fetch()` to request data from a public API.
- Parsed JSON responses.
- Implemented loading and error messages.
- Built a GitHub profile finder using the GitHub API.

### 5. Bootstrap and Tailwind CSS
- **Bootstrap:** Grid system, navbar, cards, buttons, and utility classes.
- **Tailwind CSS:** Utility classes, responsive prefixes, hover states, and custom styling.
- Compared component-based styling with utility-first styling.

### 6. React *(Upcoming)*
- Vite setup, JSX, components, and props.
- Lists, conditional rendering, and state management.
- Forms, event handling, and React Hooks.
- API integration and routing.
- Context API and introduction to Redux Toolkit.
- Introduction to Next.js and rendering concepts.

## ▶️ How to Run the Projects

1. Clone the repository:

   ```bash
   git clone https://github.com/SriSarvesh08/frontend-checklist.git
   ```

2. Open the project folder in VS Code.

3. Open the required task folder.

4. Run its `index.html` file in your browser or use the VS Code Live Server extension.

Some tasks use external CDN resources and require an internet connection.
